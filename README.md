# UslessTools

A personal grab-bag of small scripts, experiments, and utilities. Not polished, not curated — just useful things collected over time.

## What's in here

| Folder | What it does |
|---|---|
| `PDFViewer/` | Simple Tkinter-based PDF viewer scripts |
| `Pillow/` | Small image manipulation experiments (resizing, effects) using Pillow |
| `Scraping_tools/` | Two scraper setups — one with BeautifulSoup, one with Scrapy |
| `book_analyzer/` | Streamlit app for text/book analysis (word frequency, readability, etc.) |
| `diagram_to_maremaid/` | Script to convert diagrams into Mermaid syntax |
| `string_art/` | Generates string art patterns (HTML/JS + Python) |
| `mixed/` | Miscellaneous one-off scripts (PDF conversion, reading, etc.) |
| `jokes.md` | Exactly what it sounds like |

## Notes

- Several folders have `old/` or `backup/` subfolders with earlier iterations of the same scripts — kept for reference, not necessarily working.
- Each tool is independent; there's no shared setup. Check individual scripts or `requirements.txt` files (where present) for dependencies.
- This is a personal toolbox, not a maintained package — expect rough edges.
